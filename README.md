# Grendene Catalog

Aplicativo Android para consultar e organizar produtos, fábricas, cores e fotografias, com tema escuro e armazenamento local.

**Versão:** 0.3.0  
**Android mínimo:** 8.0 (API 26)  
**Idioma:** português

O catálogo, as fotos cadastradas e a pesquisa visual local funcionam offline. A busca de fotos em sites e as atualizações pelo GitHub precisam de internet.

## Instalação

1. Transfira `GrendeneCatalog-0.3.0.apk` para o celular.
2. Abra o arquivo e autorize a instalação por essa origem se o Android solicitar.
3. Abra o aplicativo e aguarde a preparação inicial do catálogo.

Para atualizar uma das versões anteriores desta entrega, instale por cima, **sem desinstalar**. A versão 0.3.0 mantém o pacote e a assinatura das versões 0.1.0 e 0.2.0.

## Funcionalidades

- Pesquisa por código ou descrição, cor e fábrica.
- Rolagem automática para mostrar os resultados da pesquisa.
- Aba **Produtos** com filtro por fábrica.
- Cadastro e edição com seleção da fábrica em uma lista.
- Códigos armazenados como texto, preservando zeros à esquerda.
- Várias fotos por produto, com seleção de imagens diretamente no cadastro.
- Visualização em tela cheia, miniaturas, zoom por pinça, arraste e toque duplo.
- Produtos recentes e favoritos.
- Pesquisa visual aproximada por uma foto da galeria ou da câmera.
- Busca de fotos online no catálogo Multigiro, com seleção manual das imagens corretas.
- Exclusão de produtos e fotos com confirmação.
- Importação de Excel `.xlsx`, com prévia e escolha entre atualizar ou ignorar produtos existentes.
- Exportação e importação de backup completo.
- Compartilhamento do aplicativo e do catálogo para outro celular.
- Preparação para avisos e download de atualizações pelo GitHub Releases.
